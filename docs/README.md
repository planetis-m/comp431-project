# Documents

This directory keeps course material and project notes.

- `assignment/` contains the original course PDFs.
- `extracted_text/` contains text extracted from those PDFs so the report can
  be checked against the requirements without opening the PDFs.
- `attack_surface_analysis.md` is the project's local notes on the audited
  parser surface.

The `.txt` files intentionally duplicate the PDFs in a searchable form.
